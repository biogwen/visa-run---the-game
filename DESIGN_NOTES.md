# Design Notes

This wiki is a working design document for a prototype.

## Core design sentence

Everyone needs the group to escape, but almost nobody can be fully honest about their situation.

## Playtest priorities

After each playtest, record:

- Did players understand the objective?
- Did private chats create tension?
- Did documents feel fun or too complex?
- Did Heat matter?
- Did Deported players stay engaged?
- Which roles were boring?
- Which roles created strong stories?

## Balance reminder

Do not balance from theory alone. Playtest first.
