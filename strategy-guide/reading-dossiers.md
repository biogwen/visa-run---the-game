# Reading Dossiers

A Dossier tells a story.

## Questions to ask

- Which document is missing?
- Which document changed after setup?
- Which document was defended too hard?
- Which document was never tested?
- Which player benefits if this Dossier fails?

## Important distinction

A bad Dossier does not equal an evil player.

A pattern of causing bad Dossiers is much more suspicious.
