# Dossier Structure

Each Dossier has 4 layers.

## 1. Identity

The player's public or semi-hidden profile.

Examples:

- Tourist
- Remote Worker
- Freelancer
- Founder
- Backpacker
- Consultant
- Crypto Nomad

## 2. Core Documents

Usually required to leave.

- Passport
- Visa Stamp
- Exit Ticket
- Entry Proof

## 3. Supporting Documents

Useful for strict border checks.

- Proof of Funds
- Travel Insurance
- Local Address
- Embassy Letter
- Bank Statement
- Police Clearance

## 4. Hidden Complication

A secret weakness or risk.

- Overstay Risk
- Expired Visa
- Wrong Name
- Remote Work Exposure
- Missing Exit Ticket
- Fake Proof of Funds

## Recommended physical layout

```text
PLAYER DOSSIER

Identity:
[Identity Card]

Core Documents:
[Passport] [Visa Stamp] [Exit Ticket] [Entry Proof]

Supporting Documents:
[Slot 1] [Slot 2] [Slot 3]

Hidden Complication:
[Hidden Complication Card]

Status Tokens:
[Flagged] [Audited] [Compromised] [Cleared] [Deported]
```
