# Core Documents

Core Documents are the main documents needed to leave.

## Standard core documents

- Passport
- Visa Stamp
- Exit Ticket
- Entry Proof

## Standard exit requirement

At normal Heat, a player usually needs:

- Valid Passport
- Valid Visa Stamp
- Valid Exit Ticket

At higher Heat, Entry Proof and Supporting Documents become more important.

## Design purpose

Core Documents are easy to understand. They make the game accessible while still allowing hidden validity and Scammer manipulation.
