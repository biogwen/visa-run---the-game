# Heat Thresholds

Use these default Heat thresholds.

| Heat | Effect |
|---:|---|
| 0 | Normal pressure |
| 1 | Light suspicion |
| 2 | Supporting Documents matter |
| 3 | Suspicious documents become risky |
| 4 | Border checks become strict |
| 5 | Random audits before exit |
| 6 | Border lockdown |

## Prototype rule

At Heat 6, Scammers usually win unless a rescue effect is active.
