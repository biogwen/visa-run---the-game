# How to Resolve Ambiguity

Ambiguity is part of the game, but rulings must be consistent.

## Fixer priorities

1. Follow the card text.
2. Follow the script rules.
3. Preserve hidden information.
4. Keep the game fair.
5. Choose the ruling that creates the most interesting tension without feeling arbitrary.

## Public rulings

If a rule affects everyone, explain it publicly.

## Private rulings

If a ruling reveals hidden information, explain only what the player is allowed to know.
