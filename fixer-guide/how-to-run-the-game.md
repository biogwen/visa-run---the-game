# How to Run the Game

The Fixer is the Game Master.

The Fixer does not play against the players. The Fixer manages tension, hidden information and fair resolution.

## Responsibilities

- Prepare the script
- Build starting Dossiers
- Run the Night Phase
- Reveal Crisis Cards
- Track Heat
- Resolve audits
- Answer rules questions
- Run the Final Border Check

## Golden rule

Give clear information, but never more information than the rules allow.
