# How to Balance the Game

Balance in Visa Run comes from information, Heat and Dossier fragility.

## If Nomads win too easily

- Add more Suspicious documents
- Add one stronger Scammer role
- Increase Heat penalties
- Reduce early audit clarity

## If Scammers win too easily

- Add more repair options
- Reduce Heat gains
- Give Nomads one more information role
- Start with fewer fake documents

## If the game is too confusing

- Make identities public
- Reduce document states
- Use only Valid, Fake, Expired and Suspicious
