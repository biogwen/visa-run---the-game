# Setup Procedure

## Setup steps

1. Choose player count and script.
2. Select roles.
3. Build the Crisis deck.
4. Build Dossiers.
5. Add Hidden Complications.
6. Prepare Heat Track.
7. Prepare status tokens.
8. Give players their role and Dossier.
9. Explain the premise and objective.
10. Begin Night 1.

## Fixer check

Before starting, make sure the Nomads have a possible path to victory and the Scammers have enough tools to create pressure.
