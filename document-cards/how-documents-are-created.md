# How Documents Are Created

Documents enter the game through setup, roles and crises.

## Setup creation

The Fixer creates each starting Dossier before the game begins.

## Role creation

Examples:

- Fake Visa Agent adds a fake document.
- Local Fixer repairs a document.
- Border Runner moves a document.
- Embassy Contact clears a document.

## Crisis creation

Some crises create documents, such as:

- Emergency Embassy Letter
- Private Agent Receipt
- Last-Minute Exit Ticket

## Important rule

Newly created documents should not automatically be trusted.
