# Heat Track

The Heat Track should be visible to everyone.

## Track values

0, 1, 2, 3, 4, 5, 6

## Labels

- 0: Normal
- 1: Light suspicion
- 2: Support required
- 3: Suspicious risky
- 4: Strict checks
- 5: Random audits
- 6: Lockdown

## Print advice

Use a single marker that moves along the track.
