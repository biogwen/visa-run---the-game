# Night Phase

During the Night Phase, The Fixer secretly wakes roles that act at night.

## Common night actions

- Check a document
- Add a fake document
- Block an ability
- Protect a Dossier
- Swap documents
- Repair a document
- Corrupt information

## Information discipline

The Fixer should give only the information allowed by the ability.

If an ability checks a document, do not reveal the player's full alignment unless the role explicitly allows it.

## Night order

A standard night order is:

1. Protection abilities
2. Blocking abilities
3. Document creation or tampering
4. Investigation abilities
5. Repair abilities
6. Special independent abilities

Scripts may change this order.
