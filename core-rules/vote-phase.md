# Vote Phase

During Vote Phase, the group chooses one major action.

## Common vote options

- Audit a player
- Audit a document
- Deport a suspect
- Clear a player
- Spend a shared resource
- Trust an agent
- Ignore the crisis

## Voting format

The default format is majority vote.

The Fixer counts votes and resolves ties using the script rules.

## Recommended tie rule

If there is a tie, no action happens and Heat increases by 1.

This makes indecision dangerous.
