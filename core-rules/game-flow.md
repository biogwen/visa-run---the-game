# Game Flow

The game is divided into days. Each day has a public crisis, private discussion, group pressure and one major decision.

## Full daily structure

1. Night Phase
2. Morning Briefing
3. Private Chats
4. Public Accusation
5. Vote Phase
6. Crisis Reveal

## Why this structure works

The Night Phase creates hidden changes.

The Morning Briefing creates a public problem.

Private Chats let players negotiate, lie and compare information.

Public Accusation turns private suspicion into group pressure.

The Vote Phase forces the group to commit.

The Crisis Reveal creates consequences and moves the game toward the Final Border Check.
