# Night Order

Use this standard night order unless a script says otherwise.

1. Roles that become protected
2. Scammer blocks
3. Scammer document creation or tampering
4. Scammer swaps or theft
5. Nomad checks
6. Nomad repairs
7. Independent abilities
8. Fixer cleanup

## First night

On the first night, skip abilities marked "not first night" if your script uses that rule.

## Fixer advice

Keep a night sheet. Track every action, target and result.
