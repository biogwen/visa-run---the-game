# Independent Roles

## Crypto Bro

Each day, privately give one player a Shortcut Token.

A Shortcut Token can temporarily treat a Missing, Expired or Suspicious document as acceptable for one action.

Each used Shortcut Token increases Shortcut Risk by 1.

Crypto Bro wins if Shortcut Risk reaches 3 before Final Border Check and Crypto Bro is not Deported.

At Shortcut Risk 3, Heat +1.

## Chill Guy

Wins if the game reaches Day 5 and they are not Deported.

## Fake Rich Nomad

Wins if they pass the border without valid Proof of Funds.
