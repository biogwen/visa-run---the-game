# Beginner Standard Game Overview

The beginner game uses 9 players:

## In play

Nomads:

- Embassy Contact
- Remote Worker
- Paranoid Planner
- Overstayer
- Backpacker
- Local Fixer

Scammers:

- Fake Visa Agent
- Corrupt Officer

Independent:

- Crypto Bro

## On the script but not necessarily in play

- Border Runner
- Travel Agent
- Document Clerk
- Embassy Intern
- Insurance Broker
- Passport Thief
- Chill Guy
- Fake Rich Nomad

The Fixer should say:

> All roles on the script may or may not be in play.
