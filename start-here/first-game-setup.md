# First Game Setup

This setup is recommended for the first playable prototype.

## Player setup

Use 9 players total:

- 1 Fixer
- 6 Nomads
- 2 Scammers
- 1 Independent

## Suggested roles

Nomads:

- Embassy Contact
- Remote Worker
- Paranoid Planner
- Overstayer
- Backpacker
- Local Fixer

Scammers:

- Fake Visa Agent
- Corrupt Officer

Independent:

- Crypto Bro

## Starting documents

Each player receives:

- 3 Core Documents
- 1 Supporting Document
- 0 or 1 Hidden Complication

The Fixer should make sure not every Dossier is equally safe. Some should be clean, some fragile, some misleading.

## Starting Heat

Heat starts at 0.

## Crisis deck

Use 5 Crisis Cards for the first game:

1. Random Document Check
2. Embassy Queue Collapse
3. Remote Work Crackdown
4. Surprise Police Check
5. Final Border Window
