# Quick Start Guide

Use the **Beginner Standard 9-Player Script** for a first game.

You need 9 players + 1 Fixer.

The game lasts up to 5 days.

The day structure is:

1. Night Phase
2. Morning Briefing
3. Private Chats
4. Public Debate
5. Official Check Phase
6. Vote Phase
7. Crisis Reveal

Nomads need **5 legal exits** to win.

Scammers win if **4 or fewer players** can legally leave.
