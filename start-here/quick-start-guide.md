# Quick Start Guide

Use this page to run a first game without reading the entire wiki.

## Recommended first game

- Players: 9
- Duration: 60 to 75 minutes
- Teams: 6 Nomads, 2 Scammers, 1 Independent
- Days: 5 maximum
- Starting Heat: 0

## Setup

1. The Fixer explain the goal.
2. Choose a script, preferably the Beginner Script.
3. Give each player one hidden Role card.
4. Give each player a Dossier with documents.
5. Give some players Hidden Complications.
6. Put the Heat marker at 0.
7. Prepare 5 Crisis Cards.
8. Start with Night 1.

## Day structure

Each day has 6 phases:

1. Night Phase
2. Morning Briefing
3. Private Chats
4. Public Accusation
5. Vote Phase
6. Crisis Reveal

## End of game

At the end of Day 5, The Fixer resolves the Final Border Check.

Nomads win if enough Active players can legally leave.

Scammers win if too few players can legally leave, or if a special Scammer victory condition is met.
